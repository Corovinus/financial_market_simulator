# Шрифт оригинала

`keyrus_8x16.bin`: 4096 байт, 256 символов по 16 строк по одному байту.
Извлечён штатной командой `KEYRUS /FILES` из предоставленного KEYRUS.COM
внутри DOSBox-X; исходное имя `_08X16.FNT`. Не заменён системным шрифтом.
Кодировка CP866, старший бит — левый пиксель. В режиме VGA text девятый
столбец используется для продолжения некоторых символов рамок.
Права на исходные данные принадлежат их правообладателям; лицензия на
распространение комплекта за пределами этого проекта не исследовалась.
